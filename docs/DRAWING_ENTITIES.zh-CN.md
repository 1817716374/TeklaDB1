# DG 图元：type-311 线段字段

`Drawing::lineSegments` 暴露 type-311 每条记录的 ID 和两个已存 XY 坐标，并记录原始行偏移。坐标来自 payload@24、@32、@40、@48 四个 little-endian double。每条 120 字节原始记录仍完整保留在 `Drawing::raw`；其余字段、线型、所属视图、可见性、线宽以及绘制顺序尚未命名。

## 证据与边界

固定语料中的 506 个 DG 覆盖 8 个保存版本。type-311 总计 497,725 行：7.13 为 956、7.30 为 49,483、7.64 为 62、7.82 为 443,960、8.44 为 6、8.95 为 3,211、9.08 为 0、9.54 为 47。每行的四个候选坐标在这些样本中均为有限数；16 行 7.30 记录和 1 行 9.54 记录为退化/零端点形式，照样保留。稳定行宽和跨版本数值检查支持读取这些存储点，但不证明所有记录都能直接渲染为可见直线。

公开 Steel Fundamentals 9.54 工程有四张包含 type-311 行的 DG，分别为 29、2、8、8 行；相应的 47 条 type-281 行均以目标类型 311 指向这些记录，47/47 的 ID 闭合。解析器只为 9.54 暴露这类记录的 ID@0、目标类型 311@4 和目标 type-311 ID@28；`candidateLineRecordOffsets` 按行头的类型/ID精确返回同图物理候选偏移：零候选保持悬空，多候选完整保留，不按 ID 静默选一条。固定公开语料逐行对照这些候选与实际 type-311 记录偏移；合成回归覆盖唯一、重复和缺失目标。中间五个字及其他行类型仍为未分类原值。部分候选线端点与已解析尺寸锚点重合。该关系布局证据只覆盖这个 9.54 工程；旧版 type-281 行宽和结构不同，本接口不把 type-281 推断成通用对象所有权或视图上下文。Tekla 的 [Drawing Line 类](https://developer.tekla.com/doc/tekla-structures/2026/line-class-67949)说明线图元由两个点定义（可带弧度参数），仅作为图元概念参考，不证明本文件中的二进制偏移。

因此，接口名表达目前最强的结构性解释；对零端点、样本外版本或输出渲染，不做补值、筛除或自动关联。图纸的弧、圆、多段线、文字、符号、图层、风格及完整实体拓扑仍未恢复。

## type-304 物理目标行候选

`DrawingRecordAssociationIndexEntry::candidateTargetRecordOffsets` 按 type-304 保存的目标表类型和记录 ID，列出同一 DG 中目标表那些 `payload@0` 等于表类型且 `payload@4` 等于该 ID 的行偏移。对固定的506张、8个存储版本的可解析图纸，共审计1,233,185条索引；1,222,374条至少命中一行，90条命中重复 ID 并完整保留全部候选，10,811条没有符合条件的目标行，主要来自8.95 type-259。无候选代表当前DG中没有可验证的物理目标，不会从相同数字或第三个索引字推断替代关系。命中只建立文件内原始记录索引，不代表对象所有权、绘图可见性或 DB1 跨文件关联。固定语料校验器逐条将候选偏移与原始行重新对照；合成回归覆盖无目标、唯一目标和重复目标。
