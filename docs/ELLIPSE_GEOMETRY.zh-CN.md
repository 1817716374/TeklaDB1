# ELD椭圆截面与折梁坐标传递

`ELDd1*r1*d2*r2`的两组尺寸描述两端椭圆。当前OCCT支持两端相同的实心椭圆，生成解析曲线而非矩形包络或十六边形；支持已有直杆、折线路径和后续实体操作。不同端尺寸的变截面ELD仍待独立样本验证，明确报告未构建，不使用错误矩形代替。项目目录仍优先，已有但未解释的同名目录不会被名称推定覆盖。

参数来源为[官方预定义参数型材](https://support.tekla.com/doc/tekla-structures/2026/mod_available_parametric_profiles)的Circular sections，以及[2026建模手册](https://support.tekla.com/dist/sxf/document/TS_MOD_2026_en_Create_models.pdf)1032页示意图。图中的d1/r1与d2/r2属于两端尺寸，不能相加。真实证据目前是7.30公开工程中的12个`ELD50*25*50*25`，不能将这些相同参数对象视为不同参数/不同版本的独立验证。

## 修正内容

原实现将这12个对象作为100×25矩形包络，实际截面为50×25椭圆。新实现使用OCCT解析椭圆边界，保持原对象、路径和坐标数据。零尺寸、异常数值和未支持的变截面明确失败。目录别名中的数值溢出也不会中止其他有效构件的构建。

折梁原来把固定初始secondary或normal投影到每一段。这对截面轴斜置于路径平面的对象会产生额外扭转。现在在相邻切线间用最小旋转传递正交截面基；保留原有斜接延伸/裁剪。180度反向不能形成有限斜接，继续报告未构建。真实验证覆盖平面折梁；任意空间路径、变截面、更多扭转规则仍是后续工作。

## 独立验收

`tests/geometry-corpus.json`复用原固定DB1和IFC，不改变主语料指纹：

- 4个直杆、8个折梁，共12个固定对象ID及7,872个IFC顶点；逐一核对GUID、实体有效性和世界坐标到实体表面的距离，阈值0.02毫米。
- IFC将椭圆存成16点多边形。验证器先从4个独立直杆端环恢复半轴和等角采样，计算解析面积与多边形面积比，再对IFC BREP有向面求体积并作表示差异修正。不能把多边形体积直接当成解析曲面体积，也不调用生产截面公式来生成期望值。
- OCCT体积采用自适应高精度积分；真实体积相对阈值1e-5。默认积分在裁剪椭圆面上存在可见数值误差，不能用放宽阈值掩盖。
- 合成检查包含两种轴方向、圆形极限、旋转坐标、斜置截面90度转角、曲面点和体积、网格生成、错误/溢出/变截面参数及目录优先级。安装后的独立消费项目执行同一几何检查。
- 整模型1,240个实体仍全部有效。12个ELD发生预期的大幅体积修正；另一个`2*2300`构件因坐标正交化产生约2.84e-6相对体积变化，追加该对象16个IFC顶点和独立BREP体积对照。其余构件未出现超过0.02毫米包围盒或1e-6相对体积的变化。

解析椭圆的真实包围盒与16边形导出在本工程有约0.311毫米差异：多边形未采样到旋转后椭圆的精确极值。这是表示差异，应以截面拟合、表面点和修正后的体积联合验收，不能再次把解析椭圆压缩到多边形包围盒。

另用[同工程DWG导出](https://btscm.fr/dicocm/R/realisations/Lapechelire/EXPORTS%20DAO/lapechelire.dwg)交叉调查。9,539,622字节，SHA-256为`b2fda60653ca4651675b3ed0a26477c6620dcf4a07764d65f8fc0ba40008e6b7`。独立LibreDWG读取到1,541个唯一TeklaStructures对象ID，与IFC产品全部对应：1,240个构件、301个机械紧固件。它是三维网格，不能证明DG纸面变换。两个ELD折梁在DWG与IFC之间本身约有0.0153毫米顶点差异；保留该差异，不宣称导出完全相同。

这项修正不意味着完整几何已恢复。ARVAL包络、部分加工与布尔、螺栓头/螺母/垫圈、焊缝、变截面ELD及更多曲线路径仍需继续逆向。
