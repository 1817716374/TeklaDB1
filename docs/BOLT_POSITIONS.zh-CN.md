# 螺栓位置数组与空引用

`BoltGroup::positionArrayId`保存现代表中的原始位置数组引用：有值0表示文件没有保存该数组引用；有值非零必须能连接相应轮廓块；`nullopt`表示该布局未解码此字段（例如历史7.30入口）。该字段不替代`positions`，也不用于推断删除、禁用或生命周期状态。

非零引用仍逐点恢复已有坐标。显式0或已存在的空数组保留螺栓组、定义、起终点、placement、关联构件和属性，`positions`保持空并产生包含对象ID的诊断。起终点只是螺栓组的参考点，不能据此生成一颗位于原点的螺栓。8.95轮廓块中的隐式首点规则只适用于实际存在的块，不适用于零引用。

OCCT遇到空位置数组时不构造空compound冒充成功；组ID进入`OcctGeometryModel::unbuiltBoltGroupIds`，并提供诊断。缺失定义也列入该索引。已保存的非空位置仍按原逻辑构形，核心模型保留所有组。
