# DB1 9.08：官方考试工程的混合布局

主模型和 xslib 的 9.08 部分语义已恢复；工程入口报告 `PartialSemantic`。这不是 9.08 全部语义、完整几何或同版本 DB2 的完成声明。

## 固定来源及独立证据

样本来自 Trimble 的 [TSOpenAPI_Model_Exam](https://github.com/TrimbleSolutionsCorporation/TSOpenAPI_Model_Exam)。固定两个提交的 `API_Developer_Exam_01.zip`：

| 快照 | 提交 | 主库实际构件 | 加工构件 | 梁候选 |
|---|---|---:|---:|---:|
| 2021-07-08 | `7345e5f14c86bf94f9da073705c56526d6895c6d` | 5,360 | 1,683 | 4,237 |
| 后续 9 月模型 | `d6bead19ff88c05c6a079c406bbaa64766063753` | 5,381 | 1,683 | 4,254 |

它们是同一工程的两份快照，不能算作两个独立项目。每份固定主库、组件库、profdb.bin 和模型 XML；另固定 7 月同次提交的 [Form1.cs](https://github.com/TrimbleSolutionsCorporation/TSOpenAPI_Model_Exam/blob/7345e5f14c86bf94f9da073705c56526d6895c6d/Example_Test_Project/Form1.cs)。文件及压缩包的大小、SHA-256、成员路径均记录于 `tests/corpus.json`，模型不随库再分发。

官方代码检查 `ModelObjectEnum.BEAM` 的数量为 4,237。7 月模型的 class kind 2、definition subtype 为 10 的倍数的构件数量与之相符；这是一项总数证据，不能单凭它证明所有子类型枚举或几何含义。9 月模型不得套用 7 月数量。模型 XML 标注 Tekla Structures 2021，包内 2012 年报表也不作为当前模型真值。

两份主库各有 49 份构件定义的 family + dimension 名称与独立的 profdb.bin 名称完全吻合。将编号前缀误当 family 只会碰巧匹配两项；组件模板的参数化名称没有固定型材匹配，不伪造结果。

## 已确认布局

以下偏移不含分配标签，主库共 339 节，组件库共 303 节。按版本、角色、尺寸、字段数及引用标志精确校验。

| 记录 | 主库 / xslib 表序号 | 载荷字节 | 已恢复内容 |
|---|---|---:|---|
| 身份 | 293 / 260 | 55 | ID@0、class reference@4、owner@8、GUID@16 |
| 身份分类 | 329 / 293 | 44 | ID@0、record kind@4；完整载荷公开为 rawPayload |
| 构件定义 | 299 / 264 | 332 | 名称@54、family@76（64字节）、dimension引用@140、材质@228（32字节）；@144是编号前缀 |
| 字符串属性 | 116 / 90 | 116 | 旧字符串记录布局及属性关系 |
| 轮廓块 | 328 / 292 | 456 | 双精度坐标数组；不能套用8.95的单精度轮廓 |
| 螺栓定义 | 327 / 291 | 312 | ID、已存数量、类别/名称/标准；尾部60字节保留 |
| 螺栓组 / 层 | 310 / 274、332 / 296 | 24、48 | 已存位置、放置引用、连接及层记录 |

主库两份快照均保留 1,850 个螺栓组、316 份螺栓定义、104 个 kind-39 未解读构件。xslib 恢复 42 个构件、34 个装配、179 份参数定义和9份自定义组件定义；公式保留引用图，不执行求解。数量和语义指纹是回归基线，不是独立真值。

`BoltDefinition::legacy908Parameters` 保留载荷 `[252,312)`。当此字段存在时，`diameter`、`tolerance`、`length`、`extraLength`、`boltType` 的零值表示未解读，**不是测得为零**。OCCT 明确将这些螺栓组列为未构建，不能根据猜测参数生成实体。构件未知轮廓种类、复杂加工、对象生命周期仍存在缺口。DB2 9.08 目前仅能保留原始容器，未开启编号语义。

## 复验

核心 CTest 增加21项正常/异常输入：主库/组件库、双精度轮廓、未知类型、完整分类载荷、螺栓原始参数、断链、签名错误、重复身份与非有限放置。另有 OCCT 拒绝未核实螺栓实体的测试，以及安装后主库/组件库消费测试。

```sh
python -B tools/test_schema908_evidence.py --data /path/to/corpus --download --exe /path/to/tekladb1_validate --work /path/to/separate-work
```

该检查验证官方数量与49个型材名称，并用错误对象分类、错误型材族、篡改官方计数三种变异确认检查有效。另核对所有身份/分类原始记录、螺栓原始参数及工程主库→组件库关联；后者属于内部一致性。Windows 的测试数据与 work 路径应放在 E 盘。完整语料由 `tools/corpus.py` 复验。
