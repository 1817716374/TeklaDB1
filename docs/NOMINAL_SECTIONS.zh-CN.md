# 无目录时的 UPE/IPE 几何与折线斜接

此前，OCCT后端在找不到型材目录时用高度比例估算UPE/IPE的宽度、腹板和翼缘。该公式生成的形状可以通过拓扑有效性检查，但公开7.30工程中24根UPE140与1根UPE220的体积比独立IFC少约20.56%和16.86%。因此，`BRepCheck`成功不能当作尺寸正确的证据。

## 公称尺寸与来源

现使用制造商公布的离散尺寸，支持14种普通UPE（80–400）及18种普通IPE（80–600）。数据来自ArcelorMittal Orange Book的 [UPE尺寸表](https://orangebook.arcelormittal.com/node/253) 和 [IPE尺寸表](https://orangebook.arcelormittal.com/node/6)，查阅日期2026-09-27。只取公称高度、宽度、腹板和翼缘厚度；实现数据位于 `src/NominalSections.hpp`。

项目目录及显式截面轮廓优先。若同名目录存在但不能解释，不用公称表覆盖它；未列规格、IPE A/O/V或750多质量变体不插值、不套用普通IPE。它们仍保留DB1对象，并出现在 `unbuiltPartIds` 中。

无目录回退保留尖角表示，**不表示已取得项目目录的圆角信息或实际轧制截面**。官方圆角值不能证明某个工程采用了相同的几何表示。新增 `OcctGeometryModel::nominalProfilePartIds` 列出自身截面使用这种回退的已构建实际构件，并输出“project catalog unavailable / sharp-corner approximation”诊断。该集合不是全部几何不确定性的清单，切割工具、包络、孔、焊缝等还可能另有近似。

合成检查使用官方表的面积与根部圆角列，扣除圆角贡献后核对全部32个尖角截面；允许误差仅为原表面积最后一位的半个舍入单位及积分误差。另检查7种未知/变体名称被拒绝，以及项目目录能够覆盖公称尺寸并保留其圆角。

## 折线斜接

尺寸修正后的IFC顶点检查暴露了原有折线梁问题：代码直接将各段平头挤出后放进compound，转角处存在缺口。出错的8根UPE140为22/23点折线，全部点的倒角类型为0，不能归因为圆弧离散误差。

现在按相邻段方向求共享角平分平面，先根据截面范围及偏移延长端部，再保留平面内侧的实体。相邻段在同一平面相接，完全反向且不存在有限斜接时公开未构建对象，不返回残缺路径。新增共线、正/负90度及45度转角的体积和角点检查，安装后的独立消费程序也执行这些检查。

本轮验证了平面折线斜接；任意空间扭转、复杂自交、完整曲线扫掠仍需继续核实。圆弧路径当前仍可能用八条弦近似，相关诊断保留。

## 固定 IFC 完整实体检查

`tests/geometry-corpus.json`复用主语料清单中已有的DB1和IFC两份文件，来源、字节数及散列不变。OCCT专用检查构建模型并执行已有布尔、切割及拟合操作，再检查全部25个UPE构件：

- 身份ID和GUID与IFC一致，全部实体拓扑有效；25个公称截面来源ID均公开。
- 最终体积相对误差必须小于等于 `1e-5`（0.001%）。
- 全部1,724个IFC顶点到生成实体的距离必须小于等于0.02毫米。

本地OCCT7.9实测最大体积相对误差约 `7.34e-6`，最大距离约0.00446毫米。这里包含8根折线梁，没有将失败对象移出验证集合或放宽原有顶点阈值。制造商面积检查与项目IFC检查是不同证据：前者核对公称尺寸，后者核对这25个项目实体的尖角表示。

运行可选几何证据检查：

```text
python -B tools/corpus.py --manifest tests/geometry-corpus.json --data <external-corpus-directory> --download --exe <build>/tekladb1_ifc_geometry --report <external-report.json>
```

主语料1,408项原有基线保持不变，另增加这项可选OCCT证据检查。并不据此宣称全部IPE项目实例、ELD/ARVAL包络或全模型几何完整正确。

手工指定OCCT头文件和库的构建，安装消费时直接使用已经导出的实际路径；只有通过OpenCASCADE包目标构建时，导出配置才要求再次查找该包。这修复了手工路径模式构建成功但安装消费仍要求包配置的矛盾。

## 整模型影响核查

后续审计补充：318943/327338/327524/327681四个UPE构件仍有切割残片，边界与同工程IFC/DWG相差约6.7毫米。下列历史体积/单向顶点检查无法排除额外实体，不能据此宣称其加工后几何精确。残片、导出面共面性和下一步验收见[加工证据与限制](CUT_GEOMETRY_EVIDENCE.zh-CN.md)。

修正前后均对同一工程全部1,240个实际构件执行构建与拓扑检查，修正后无新增未构建或无效实体。72个体积变化中71个缩小与IFC数量的差异，涵盖UPE、矩形、角钢等截面；与IFC相差不超过0.01%的对象由951/1,215增至1,020/1,215。这是差异审计，不能将其余差异一律视为解析错误，也不能将数量相近等同于完整几何正确。

剩余一个变化对象91269为TUBE-25*2。IFC端部顶点显示外半径12.5、内半径10.5的十二边形截面；解析圆环与十二边形环的面积比为π/3，新体积差0.0471975511875与π/3−1一致（约9.1e-12残差）。旧斜接缺口恰好抵消了部分多边形近似差异，不能为减小这个数值而缩小圆管直径。ELD、ARVAL包络及复杂空间/曲线几何等缺口仍保留。
