# DB1 7.82：字段证据和支持边界

7.82 使用现代 section 容器，但对象布局早于 8.44。主库为 228 节，组件库为 198 节。解析器同时验证版本、表尺寸和完整字段签名，再读取已恢复的角色。以下偏移全部相对于 payload，不包含行标签。

- [mohsen-azimi / publications](https://github.com/mohsen-azimi/publications)：`J6_SHM_using_Extremely_compressed_Data/Figures/MOHSEN` 中的主库及近空 xslib。

## 独立螺栓与关联

定义 type 2 为普通构件，11/38 为减/加布尔操作，10 为独立螺栓。7.82 不存在已验证的现代 BoltGroup 表：

```cpp
for (const auto& bolt : model.individualBolts) {
    const auto& stored = model.parts.at(bolt.id);
    // stored.profile: 原始尺寸/斜杠参数串；origin/axis/contour: 存储定位。
    // bolt.connectedPartIds: type-10 关系指向的普通构件。
}
```

不使用默认直径，不假定头部、螺母、孔或螺栓组平面，也不从未命名的斜杠参数推导实体。`boltGroups` 不重复放入这些旧记录。布尔操作、焊缝和螺栓连接通过关系表恢复；装配由主构件和身份表的装配引用组成，排序去重。

## 验证与未完成项

四份文件通过语义读取；两个工程目录聚合 DB1/xslib、DB2、DBV 和可用目录资源。`readProject` 将 7.82 主库与组件库标为 `PartialSemantic`。合成回归检查完整签名、记录宽度、坐标/轮廓/定义连接、字符串循环/缺块、螺栓连接、非有限数值、整数溢出及未解析装配诊断。

未知表可由 `parseRawDatabase` 保留。参数表达式不等于完整执行组件；type-39、非板轮廓、螺栓精确几何和标签生命周期仍待验证。当前偏移来自样本交叉分析，数量与语义指纹用于检测回归，尚无 Tekla/IFC 独立导出对照，不能宣称 7.82 或全格式完整逆向。

## xslib 自定义构件定义

组件库 ordinal 125 的 payload 为 32 字节，字段签名为 `[1,0,0,0,0,0,0,0,0]`。PSDBIM 有 40 条，MOHSEN 为空。偏移均从 payload 起算：

| 偏移 | 内容 |
|---|---|
| 0 / 4 | 定义 ID / 原始 kind（样本均为 4） |
| 20 | 原始 classificationCode；尚未赋予枚举语义 |
| 24 | 说明字符串链 ID，解码为 `description` |
| 28 | 名称字符串链 ID，解码为 `name` |

复用 `CustomComponentDefinition`；`referenceIds[0..1]` 保存上述两个引用，第三项为零，旧布局没有第三个引用。GUID 来自同 ID 身份记录。身份 owner 将 660 条参数、2,726 条子对象身份关联到这 40 条定义（子对象包括参数、辅助对象等，不能当作 2,726 个几何构件）。自身 owner 不重复放入子列表。

28 条具名记录覆盖 18 个不同名称，全部与同提交 `ComponentCatalog.txt` 的 `-10` 分类名称相符；另有 12 条空名称。重复名称各自保留，例如 Anchor-Bent Rod 有 5 条；无法据此挑选“当前版本”。目录的 `-10` 不等同于二进制 classificationCode。连接类记录仍在 `Model::components`，不把它们冒充 ordinal 125 的构件定义。

独立文本证据固定为 [PSDBIM 提交 5334356](https://github.com/PSDBIM/EXCEL-1246A-BLDG-B/tree/5334356d78238c8bc68b95e6b6e4f190232fa4fd) 的组件目录及四份对话框：Anchor-Bent Rod、Anchor-Epoxy、2-Angle+Plate lintel、1 Sided Beam to Column Flg MC。`legacy_component_evidence` 核对名称、所有权和 69 个 `parameter()` 引用：67 个对应 ParameterDefinition，Anchor-Epoxy 的 D5 与 lintel 的 D1 对应下述 DistanceParameter。文本中的界面类型、选项含义及公式求解没有因此得到完整验证。

缺失定义/参数身份、缺失字符串、重复定义/参数 ID、字段签名或宽度不符会拒绝语义解析。名称重复和合法空字符串不属于上述错误。真实语料指纹覆盖定义、说明、GUID、参数表达式和子对象关联；第三方文件仍由语料工具按 URL/SHA-256 单独获取。

## xslib 距离变量与公式绑定

仅对已验证的 7.82 组件库启用。两份组件库字段签名一致；PSDBIM 有非空记录，MOHSEN 对应表为空。官方文档区分距离变量与其他参数变量，并说明二者均可参与公式；这支持概念命名，但不证明下列二进制偏移或数值优先级。[Trimble 变量说明](https://support.tekla.com/doc/tekla-structures/2021/det_add_variables)

| 表 / payload / 字段数 | 已读取内容（payload 偏移） |
|---|---|
| 147 / 64 / 14 | ID@0，名称链@4，标签链@8，存储距离 double@16，第二存储 double@24，属性 token 链@56，平面 token 链@60 |
| 156 / 97 / 6 | ID@0，目标对象 ID@4，原始索引@8，表达式链@12，属性名@16（81 字节） |
| 162 / 60 / 7 | type@4，source@8，target@12；type 58 为距离绑定，type 59 为公式引用 |

上述签名均为首项 1，其余 0。147 的未解释 u32 位于 12、32、36、40、44、48、52，保留在 `rawFields`。不把第二数值或标志称作默认值、当前值、可见性或参考距离类型。属性/平面 token 保留原文，不据此补造平面坐标。

新增 `Model::distanceParameters`（6,838 条）、`formulaBindings`（10,450 条）及 `formulaBindingIdsByTarget`。距离变量保留身份、owner、名称、标签、数值、token 和两个绑定对象；组件与自定义构件定义均提供参数/距离/公式的归属列表。普通参数的 `expression` 仍表示原有表中存储的字符串；实际属性公式由 FormulaBinding 单独保存，不能用一个覆盖另一个。

13,676 条 type-58 关联恰好为每个距离变量提供两个对象。24,442 条 type-59 关联分别包含一次公式目标及其余引用；目标可为构件、参数、距离、焊缝、组件或其他身份对象。`referencedObjectIds` 保留全部引用，`inputObjectIds` 保留非目标的 13,992 条引用。360 条引用跨越 owner，合法保留。表达式可能读取其自身目标，因此后者并非完整的词法依赖图；尚不据此判定求解顺序或无环性。

具体证据：D5 / 112715 属于 Anchor-Epoxy / 112580，标签为 Plate Thickness，存储距离为 12.7；D1 / 32158 属于 lintel / 31989，标签为 Lintel length。公式 112771 的目标是 D6 / 112718 的 `proVALUE`，表达式为 `P6+D5`，非目标引用恰为 P6 / 112624 与 D5 / 112715。`legacy_component_graph_evidence` 逐项核对这些关系，并为全部变量、公式、存储值、原始标志、归属和引用记录语义指纹。

解析器拒绝缺失身份/owner/字符串/目标、重复变量/公式 ID、非有限数值、无对应源的 type-58/59 关联、距离绑定数量不是 2、公式引用中目标不是恰好一次。API 不执行 `fP`、`fTpl`、`fVF` 等函数，不读取表达式中的路径，也不访问其引用的外部资源。表达式求值、模型几何约束求解、索引含义、记录生命周期及其他版本的此类表仍为缺口。
