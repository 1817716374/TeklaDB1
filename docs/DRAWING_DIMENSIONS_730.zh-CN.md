# DG 7.30 直线尺寸

`parseDrawing`复用`straightDimensions`、`straightDimensionSets`与`unhandledDimensionRecordIds`接口，恢复已验证的7.30子类型0。35份固定公开图纸共有341条尺寸、187条链，其中313条尺寸已解读，28条子类型1保持原始载荷并列入未处理ID；其所属链仍保留该ID。不能因为9.54的同码已有解释，就将其应用到旧版。

## 字段与边界

相对负载首字节，type256宽1400字节，type257宽136字节。已验证字段偏移与9.54一致：类型@0、ID@4、上下文@8、所属链@12、子类型@16、起点@24、终点@48、方向@168、已存有符号距离@192。尺寸链仅解读类型、ID和上下文；其他字段继续保留。

检查非零/唯一ID、所属链存在、上下文相符及视图上下文存在。旧版歧义或退化视图不产生唯一视图索引，尺寸保留上下文ID并给出诊断；调用者须先检查`viewsByContext.find`。非有限坐标被拒绝，非单位XY方向或端点不共面仍保存参数但不提供投影长度。尺寸链的ID顺序是文件顺序，不代表空间排序。

这些限制与[公开尺寸接口](DRAWING_DIMENSIONS.zh-CN.md)一致。格式化文字、箭头、引出线、隐藏状态、单位转换、覆盖值、纸面比例与完整渲染仍有缺口；尺寸值不由四舍五入后的文字替代。

## 独立 DWG 几何证据

来源为同一教学工程的[二维出图目录](https://btscm.fr/dicocm/R/realisations/Lapechelire/Modele%20TEKLA/pechelirejulV1/pechelirejulV1/Fichiers_DWG/)，文件`ensemble passerelle.dwg`。清单固定其878,357字节大小及SHA-256 `6bc0e634d711f7eaac3a39baf9f4e98188b0e933e70a3f043f232526783e700c`，不随源码分发。使用GNU LibreDWG 0.14的`dwgread -O JSON`读取其LINE/TEXT实体，并人工核对标注和图纸位置；运行库不依赖LibreDWG，也不声称能解析DWG。

配套DB1的图纸目录以文件名`D0000516925.dg`及标题`Ensemble passerelle`确认对应关系。DID副本的尺寸、尺寸链和视图表与该文件逐字节一致，不计作独立证据。

五条独立线长乘以对应比例后，与DG端点在方向垂线上的投影相符。回归使用DWG中转录的双精度端点常量，不使用上表已舍入的图上文字作为精确长度；端点和长度阈值均为`1e-7`，当前观测误差分别小于`2.85e-14`和`9.1e-13`。

该固定出图中的视图位置相对上下文11表达。候选type260@344/352为位置、@376为比例；以起点/比例加方向×已存距离计算尺寸线起点，再将终点投影到同一尺寸线。上下文14的三条水平/竖直尺寸均使用同一个视图偏移，且与各自独立DWG端点吻合。该关系仅用于这份固定证据的回归，未作为通用纸面变换公开；其余版本、缩短或图纸状态不能据此推断。

`drawing730_dimension_evidence`核对五条线、十个端点、三个上下文及一项图纸目录标题。原始DWG由语料运行器校验散列，C++检查使用已提取并审阅的端点常量，不在运行时转换DWG。`tools/test_drawing_evidence.py`分别改动端点、方向、距离、视图位置，验证四种错误都被独立几何对照拒绝，并在变异前后检查原始对照。

## 7.82 尚未扩展

293份7.82图纸有22,844条尺寸候选；111条非零尺寸链引用不在type257中，部分候选ID出现在type314，还有视图上下文歧义。其生命周期及所属类型未确定。不能套用7.30/9.54的严格尺寸链规则导致这些真实图纸失败，也不能擅自将引用解释为删除或独立尺寸。因此7.82继续保持原始尺寸载荷与诊断，等待独立证据。
