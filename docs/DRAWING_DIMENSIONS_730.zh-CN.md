# DG 7.30 直线尺寸

`parseDrawing`复用`straightDimensions`、`straightDimensionSets`与`unhandledDimensionRecordIds`接口，现读取7.30子类型0和1。固定目录35个DG文件共341条尺寸、187条尺寸链：313条子类型0、28条子类型1均已解析并闭合到唯一尺寸链/context；目录中有DID历史副本，14条独立子类型1记录各重复一次。其他未知子类型仍保留原始载荷并列入未处理ID。

## 字段与边界

相对负载首字节，type256宽1400字节，type257宽136字节。两个已读取子类型使用同一记录前缀：类型@0、ID@4、上下文@8、所属链@12、子类型@16、起点@24、终点@48、方向@168、已存有符号距离@192。其宽度/偏移与已支持的7.64、7.82、8.44布局相符；所有28条子类型1样本数值有限、方向为单位向量、ID/尺寸链/context引用闭合。工程聚合回归核对35个文件的全部341条尺寸及尺寸链成员关系。

这证明读取的是存储端点、方向和偏移，不证明最终纸面标注值。固定语料唯一的独立7.30 DWG对应`D0000516925.dg`，该图只包含已核验的五条子类型0尺寸；其余固定DG没有配套DWG/PDF真值，不能用这份DWG外推子类型1的显示语义。子类型1的打印文字、比例/缩短及显示样式尚无独立真值。因此其`projectedLength`仅在现有XY单位方向且端点共面的条件下提供，不宣称完整标注重绘。尺寸链ID顺序是文件顺序，不代表空间排序。

检查非零/唯一ID、所属链存在、上下文相符及视图上下文存在。旧版歧义或退化视图不产生唯一视图索引，尺寸保留上下文ID并给出诊断；调用者须先检查`viewsByContext.find`。非有限坐标被拒绝，非单位XY方向或端点不共面仍保存参数但不提供投影长度。

这些限制与[公开尺寸接口](DRAWING_DIMENSIONS.zh-CN.md)一致。格式化文字、箭头、引出线、隐藏状态、单位转换、覆盖值、纸面比例与完整渲染仍有缺口；尺寸值不由四舍五入后的文字替代。

## 独立 DWG 几何证据

来源为同一教学工程的[二维出图目录](https://btscm.fr/dicocm/R/realisations/Lapechelire/Modele%20TEKLA/pechelirejulV1/pechelirejulV1/Fichiers_DWG/)，文件`ensemble passerelle.dwg`。清单固定其878,357字节大小及SHA-256 `6bc0e634d711f7eaac3a39baf9f4e98188b0e933e70a3f043f232526783e700c`，不随源码分发。使用GNU LibreDWG 0.14的`dwgread -O JSON`读取其LINE/TEXT实体，并人工核对标注和图纸位置；运行库不依赖LibreDWG，也不声称能解析DWG。

`drawing730_dimension_evidence`核对五条线、十个端点、三个上下文及一项图纸目录标题。原始DWG由语料运行器校验散列，C++检查使用已提取并审阅的端点常量，不在运行时转换DWG。`tools/test_drawing_evidence.py`分别改动端点、方向、距离、视图位置，验证四种错误都被独立几何对照拒绝，并在变异前后检查原始对照。

## DG 7.82 尺寸锚点与边界

293份真实DG含22,844条type-256尺寸记录，subtype 0/1分别为20,786/2,058。当前解析22,782条唯一尺寸ID锚点；31组重复尺寸ID的62条记录保留raw。尺寸集记录有14组重复ID（28条），因此只将唯一尺寸集放入兼容map。22,657条锚点按唯一尺寸集ID和context连接；125条唯一锚点没有唯一尺寸集，仍可读取几何字段但不会伪造所属关系。111个尺寸集引用未能在type257中唯一找到，部分相关候选ID出现在type314；其生命周期和所属类型尚未确定。视图context仍可能歧义。

完整293文件聚合基线与异常输入回归见语料清单。没有取得7.82图纸的独立打印/DWG/IFC真值，因此这批结果只验证跨版本布局一致、坐标有限性和文件内引用关系；纸面值、样式、生命周期及类型314关联仍是缺口。
